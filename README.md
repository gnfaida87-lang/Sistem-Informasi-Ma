# Flutter Dark Login Page

This is a minimal Flutter example implementing a modern, dark-mode login page (mobile portrait).

Files created:
- lib/main.dart
- lib/login_page.dart

How to run:

```bash
flutter pub get
flutter run
```

Notes:
- No external packages used (only `cupertino_icons`).
- Replace the circular logo in `LoginPage` with your real asset or network image as needed.
- The authentication (backend) hookup is left as a placeholder in `_onLogin()`.
